# Contributing

Bug reports, features, and ideas are welcome.

## Discuss, then code

Search existing issues first. If nothing covers it, open one with the Bug, Feature, or Discussion template. Wait for agreement on non-trivial work before opening a pull request. Trivial fixes (typos, obvious one-liners) can skip that.

A pull request that was not discussed and is not trivial may be closed and pointed here.

## Pull requests

Use the pull request template. Link the related issue (`Fixes #…`), summarize the change, and explain how it works in your own words.

Please describe to which degree, if any, an LLM was used in creating the pull request. Generated code is fine if it fits the surrounding style and you can explain it.

If behavior changes, add or update tests.
